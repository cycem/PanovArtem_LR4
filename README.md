# Калькулятор



Этот великолепный калькулятор на сишарпе имеет два режима работы - обычный с базовыми математическими операциями и инженерный с более сложными операциями. А еще он ведет лог файл с историей. Скачай и попробуй, ведь это так уникально и интересно!

Основной код лежит в папке src/main. Там папки:

styles - содержит библиотеку стилей
views - содержит верстку и код основного окна

а также в CalcLibrary - билибиотеке классов. там:

services - содержит вспомогательные классы для вычислений и ведения истории

прописано 2 юнит теста для проверки операции сложения и делаения на 0
