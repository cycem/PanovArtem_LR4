## 3. Протоколы взаимодействия между модулями
Протокол: вычислительный сервис (ICalculatorService)
* Участники: MainWindow (Views) -> CalculatorService (Services)
* Назначение: выполнение математических вычислений.
* Интерфейс: содержит метод вычисления Calculate, принимающий два операнда и строку операции, а также метод сброса Clear.
* Формат данных: передача примитивных типов C# (double, string).
* Правила: метод Calculate генерирует исключение DivideByZeroException при попытке деления на ноль, которое перехватывается на стороне UI.

Протокол: сервис истории (IHistoryService)
* Участники: MainWindow (Views) -> HistoryService (Services)
* Назначение: логирование и получение истории проведенных расчетов.
* Интерфейс: содержит метод добавления записи AddRecord, принимающий выражение и результат, и метод получения истории GetHistory.
* Формат данных: примитивы C# (string, double), результат возвращается в виде коллекции строк IEnumerable.
